# chabadpedia-family-trees · עצי משפחה לחב"דפדיה

כלי שעובר על ערכי האישים ב[חב"דפדיה](https://chabadpedia.co.il), מחלץ מהם קשרי משפחה עם המשפט והמקור שתומכים בכל קשר, בודק אילו משפחות כבר יש להן עץ באתר, ומייצר קוד ויקי לתבניות `עץ משפחה` ו`עץ משפחה לאדם אחד` עם קישורים פנימיים לכל אדם שיש לו ערך.

**מצב הפרויקט:** הצינור שלם ונבדק מקצה לקצה מול שרת מדומה (`tests/`), ותחביר הפלט מותאם לקוד של `תבנית:עץ משפחה` באתר. הוא עדיין לא הורץ מול האתר החי; ההרצה הראשונה דורשת כיול קצר של שדות תבנית האישים (ראו למטה). שלוש דוגמאות פלט נמצאות ב-`examples/` (הן נבנו מדפי בדיקה שנכתבו בסגנון האתר, לא מהערכים האמיתיים).

## מה מקבלים

לכל משפחה:

* `output/trees/<שם>.wiki` – התוכן לדף תבנית (`תבנית:עץ משפחת X`), כולל `<ref>` שהועתקו מהערכים, קטגוריות ו-`noinclude`.
* `output/preview/<שם>.html` (ו-`.png` עם `--png`) – תצוגה מקדימה שמדמה את התבנית, לבדיקה בלי להעלות.
* `output/review.html` – דף בדיקה: כל קשר, המשפט שממנו הוא נלקח, הערך, המקור, רמת ביטחון ודגלים ("ללא מקור", "הוסק", סתירות), וסטטוס מול עצים שכבר קיימים באתר.
* `output/ancestors/<שם>.wiki` – עץ אבות לאדם אחד (עד 3 דורות אחורה), בשתי גרסאות: הגריד הכללי, ותבנית `עץ משפחה לאדם אחד`.

שום דבר לא עולה לאתר אוטומטית. פקודת `upload` היא הרצה יבשה כברירת מחדל.

## התקנה והרצה

צריך פייתון 3.10 ומעלה. הליבה משתמשת בספריית התקן בלבד.

```bash
git clone https://github.com/Transit-Freak/chabadpedia-family-trees
cd chabadpedia-family-trees
python -m chabadtrees calibrate            # בדיקת חיבור + הדפסת תיעוד התבניות ושדות תבניות האישים
python -m chabadtrees all --png            # fetch → extract → graph → existing → render
```

או שלב-שלב:

```bash
python -m chabadtrees fetch                # איסוף כל ערכי האישים (ניתן להמשך; כשלים מנוסים שוב)
python -m chabadtrees extract [--llm]      # חילוץ קשרים (אופציונלי: גם בעזרת Claude)
python -m chabadtrees graph                # מיזוג, הצלבה, הסקות, חלוקה למשפחות
python -m chabadtrees existing             # אילו משפחות כבר יש להן עץ באתר
python -m chabadtrees render --png         # קוד ויקי + תצוגה מקדימה + דף בדיקה
python -m chabadtrees render --root "רבי פלוני" --max-depth 3      # עץ צאצאים מאדם מסוים
python -m chabadtrees render --ancestors-for "רבי פלוני"           # עץ אבות לאדם מסוים
```

הרצה בסביבת ענן של Claude Code: הסביבה חייבת לאפשר גישה ל-`chabadpedia.co.il` (Network access = Custom, להוסיף את הדומיין ואת `www.chabadpedia.co.il` לרשימה). בלי זה `fetch` ייכשל מיד.

## איך זה עובד

1. **fetch** – עובר על עץ הקטגוריות מ"אישים" (עומק עד 8), ומושך את הוויקיטקסט של כל דף ב-50 דפים לבקשה. מכבד `maxlag`, שולח User-Agent מזהה, ומאט את הקצב אחרי כל 429. כל דף שנכשל נרשם ב-`data/fetch_state.json` עם השגיאה, מנוסה שוב בסוף הריצה ובריצה הבאה (הכשלים נכנסים ראשונים לתור), ואם משהו עדיין חסר הפקודה מסתיימת בקוד 2 ומדפיסה כמה. דפים חסרים (הפניות שבורות) נרשמים בנפרד. הרצה חוזרת לא מושכת דפים שכבר במטמון (`--refresh` לרענון).
2. **extract** – שלוש שכבות: שדות המשפחה בתבנית האישיות, קטגוריות "משפחת X", ודפוסי משפט בעברית ("בנו של", "נולד לאביו X ולאמו Y", "נשא לאישה את", "חתנו של", "סבו מצד אביו", רשימות תחת "ילדיו:" וכו'). הנושא של כל ביטוי נקבע מהטקסט שלפניו: "[[X]], בנו של [[Y]]" מדבר על X; "היה חתנו של [[A]], בעלה של [[B]]" – הנושא הוא הערך, כי A הוא מושא. שרשראות יוחסין ("בנו של Y, בנו של Z") נפתרות נכון. כינויים ("הצמח צדק", "הרבי") נפתרים לערך רק אם הם ייחודיים; שמות פרטיים בלי שם משפחה לא נפתרים לעולם (יש הרבה "דבורה לאה"). לכל קשר נשמרים המשפט המקורי, ה-`<ref>` שצמודים לו, הדף והדפוס.
3. **graph** – מיזוג הקשרים: קשר שמופיע בשני ערכים מקבל דגל `corroborated` וביטחון גבוה יותר; אנשים בלי ערך ממוזגים רק כשהם קשורים לאותו אדם מקושר; הסקות (אחים חולקים הורים, חתן ⇒ בן זוג של הבת) מסומנות `inferred`; סתירות (שני אבות, הורה שנולד אחרי הילד) מסומנות ומורידות ביטחון.
4. **existing** – מאתר עצים קיימים בשלוש דרכים (קטגוריית "עצי משפחה", דפים שמשבצים את תבניות העץ, חיפוש כותרות "עץ משפחת"), קורא מי מופיע בכל עץ ואילו דפים מציגים אותו, ומדווח לכל משפחה: קיים / חלקי / אין.
5. **render** – עץ לכל קטגוריית "משפחת X" (ולכל רכיב קשרים גדול שלא מכוסה). ילד מוצג תחת ההורה שיש לו ערך (ואם לשניהם – תחת האב). זוג השורש בשתי קופסאות (`A |ד| B`, כמו בתיעוד התבנית), ובני הזוג של הצאצאים בתוך הקופסה, כמו בעצים הקיימים באתר; אם לבן הזוג יש עץ משפחה משלו באתר, מתווסף קישור אליו. הצומת ממוקם מעל הילד האמצעי (`+`) או בין שני האמצעיים (`^`). גודל עץ מוגבל (`max_tree_nodes`, ברירת מחדל 70) וענפים שנקטעו מסומנים.

## כיול מול האתר החי (בהרצה הראשונה)

`python -m chabadtrees calibrate` מדפיס את מה שצריך. הדברים שהם ניחוש ב-`chabadtrees/config.py` ואפשר לדרוס ב-`config.json`:

| מפתח | מה לבדוק |
|---|---|
| `chart.symbols` | סמלי המרצפות של `תבנית:עץ משפחה`, נגזרו מקוד התבנית עצמו: `!` אנכי, `-` אופקי, `~` מקווקו (נישואין), `ד` צומת נישואין, `ז` T למטה, `^` T למעלה, `+` הצטלבות, `)`/`(` T לצדדים, `.` `,` `'` `` ` `` פינות. תיבת טקסט תופסת 3 מרצפות והקווים מתחברים למרצפת האמצעית שלה (`box_tiles`) |
| `chart.spouse_style` | `inline` (ברירת מחדל, כמו באתר): בת מוצגת "שם, אשת [[בעלה]]" ובן "אשתו: [[...]]" בתוך הקופסה; `boxes`: קופסה נפרדת לכל בן זוג. זוג השורש תמיד בשתי קופסאות `A ~ ד ~ B` |
| `chart.mirror_horizontal` | אם בתצוגה החיה הפינות יוצאות הפוכות – להפוך ל-`true` |
| `chart.start/row/end` | שמות תבניות ההתחלה/שורה/סוף |
| `ahnentafel.params` | שמות הפרמטרים של `עץ משפחה לאדם אחד` |
| `infobox_fields` | שמות שדות המשפחה בתבנית האישיות (הפקודה מדפיסה שדות שנראים כמו שדות משפחה ולא זוהו) |
| `person_root_categories`, `exclude_categories` | מאיפה אוספים אישים ומה מדלגים |

## העלאה לאתר

עריכות המוניות בחב"דפדיה דורשות תיאום עם הקהילה (יש לאתר עמוד מדיניות בוטים ואולם דיונים לבוטים). המסלול המומלץ: להעלות ידנית 2–3 עצים לדוגמה לאולם הדיונים, לקבל אישור ודגל בוט, ורק אז:

```bash
python -m chabadtrees upload --file "output/trees/עץ משפחת פלוני.wiki" --title "תבנית:עץ משפחת פלוני"                 # הרצה יבשה
CHABADPEDIA_USER=... CHABADPEDIA_PASSWORD=... python -m chabadtrees upload ... --yes --i-have-community-approval
```

## חילוץ בעזרת Claude (אופציונלי)

`extract --llm` שולח כל ערך ל-Claude (`claude-opus-5` כברירת מחדל, עם fallback אוטומטי) ומבקש JSON של קשרים עם המשפט המדויק לכל אחד. התוצאות נשמרות ב-`data/llm_cache.json` לפי גרסת הדף, כשלים נרשמים ומנוסים שוב. דורש `pip install anthropic` ומפתח API. על 5–6 אלף ערכים זה כמה עשרות דולרים.

## בדיקות

```bash
python -m unittest tests.test_all -v
```

הבדיקות מרימות שרת API מדומה (`tests/mock_api.py`) עם 44 דפי דוגמה (`tests/fixtures/`), ובודקות בין השאר הרצה מלאה, זיהוי עץ קיים, עמידות ב-429 (אף דף לא נעלם) והמשך אחרי כשל קשיח.

## מבנה

```
chabadtrees/
  api.py        לקוח מדיה-ויקי: קצב, maxlag, 429/Retry-After, ניסיונות חוזרים, משיכה ב-50
  pipeline.py   שלבי הצינור, מצב ניתן להמשך, בחירת שורשים ובניית העצים
  extract.py    דפוסי החילוץ בעברית, תבניות, רשימות, כינויים
  graph.py      מיזוג, הצלבה, הסקות, בדיקות עקביות, משפחות
  layout.py     עץ צאצאים על גריד (Tree chart) ועץ אבות
  render.py     קוד ויקי; preview.py – HTML/PNG; review.py – דף בדיקה
  existing.py   איתור עצים קיימים וכיסוי
  llm.py        חילוץ בעזרת Claude (אופציונלי); upload.py – העלאה מבוקרת
tests/          בדיקות, שרת מדומה ודפי דוגמה
examples/       שלוש דוגמאות פלט
```
